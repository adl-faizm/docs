title: "Badge: Status and Count Indicator"
sidebarTitle: "Badge"
description: "The XLSmart Badge component displays short status labels or numeric counts, with semantic color variants for success, warning, error, and neutral states."
---

The `Badge` component displays a small label or count attached to a UI element. Use badges to communicate status, indicate unread counts, or tag items with category labels.

## Import

```tsx
import { Badge } from '@xlsmart/design-system';
```

## Variants

```tsx badge-variants.tsx
<Badge variant="default">Draft</Badge>
<Badge variant="success">Active</Badge>
<Badge variant="warning">Pending</Badge>
<Badge variant="error">Failed</Badge>
<Badge variant="info">New</Badge>
```

## Sizes

```tsx badge-sizes.tsx
<Badge size="sm">Small</Badge>
<Badge size="md">Medium</Badge>  {/* default */}
```

## Numeric count

```tsx badge-count.tsx
<Badge count={5} />
<Badge count={99} />
<Badge count={1234} maxCount={999} />  {/* displays "999+" */}
```

## With icon

```tsx badge-icon.tsx
import { CheckCircle } from '@phosphor-icons/react';

<Badge variant="success" icon={<CheckCircle weight="fill" size={12} />}>
  Verified
</Badge>
```

## Props

<ParamField path="variant" type="'default' | 'success' | 'warning' | 'error' | 'info'">
  Semantic color variant. Defaults to `'default'`.
</ParamField>

<ParamField path="size" type="'sm' | 'md'">
  Size of the badge. Defaults to `'md'`.
</ParamField>

<ParamField path="count" type="number">
  Numeric count to display instead of a text label.
</ParamField>

<ParamField path="maxCount" type="number">
  Maximum count value before showing "N+". Defaults to `99`.
</ParamField>

<ParamField path="icon" type="ReactNode">
  Optional icon before the label text.
</ParamField>
