The `Grid` component is the primary layout container in XLSmart Design System. It implements a 12-column responsive grid that adapts to any viewport size, giving you precise control over how content is arranged at each breakpoint.

## Import

```tsx
import { Grid, GridItem } from '@xlsmart/design-system';
```

## Basic usage

```tsx grid-basic.tsx
<Grid cols={3} gap={6}>
  <Card title="Item 1" />
  <Card title="Item 2" />
  <Card title="Item 3" />
</Grid>
```

## Responsive columns

Pass an object to `cols` to define different column counts at each breakpoint:

```tsx grid-responsive.tsx
<Grid
  cols={{ xs: 1, sm: 2, md: 3, lg: 4 }}
  gap={{ xs: 4, md: 6 }}
>
  <Card />
  <Card />
  <Card />
  <Card />
</Grid>
```

## Column span

Child elements can span multiple columns using the `colSpan` prop on `GridItem`:

```tsx grid-span.tsx
<Grid cols={12} gap={4}>
  <GridItem colSpan={8}>
    <MainContent />
  </GridItem>
  <GridItem colSpan={4}>
    <Sidebar />
  </GridItem>
</Grid>
```

## Props

### Grid props

<ParamField path="cols" type="number | ResponsiveValue<number>">
  Number of columns. Pass a number for fixed columns or a responsive object for breakpoint-based values. Accepts 1–12.
</ParamField>

<ParamField path="gap" type="number | ResponsiveValue<number>">
  Gap between grid cells, using the spacing scale (1–24). Defaults to `4`.
</ParamField>

<ParamField path="colGap" type="number | ResponsiveValue<number>">
  Horizontal gap between columns. Overrides `gap` for column spacing when set.
</ParamField>

<ParamField path="rowGap" type="number | ResponsiveValue<number>">
  Vertical gap between rows. Overrides `gap` for row spacing when set.
</ParamField>

<ParamField path="align" type="'start' | 'center' | 'end' | 'stretch'">
  Aligns grid items along the cross axis. Defaults to `'stretch'`.
</ParamField>

<ParamField path="justify" type="'start' | 'center' | 'end' | 'between'">
  Justifies grid items along the main axis. Defaults to `'start'`.
</ParamField>

<ParamField path="as" type="React.ElementType">
  The HTML element or component to render as the grid container. Defaults to `'div'`.
</ParamField>

### GridItem props

<ParamField path="colSpan" type="number | ResponsiveValue<number>">
  Number of columns the item spans. Defaults to `1`.
</ParamField>

<ParamField path="rowSpan" type="number">
  Number of rows the item spans. Defaults to `1`.
</ParamField>

<ParamField path="as" type="React.ElementType">
  The HTML element or component to render as the grid item. Defaults to `'div'`.
</ParamField>
