    The XLSMART elevation system communicates visual hierarchy and the spatial relationship between surfaces. Elevation helps users identify which elements are on the base surface, raised above content, or temporarily displayed as overlays.

    ## C. Usage

    ### 1. Shadow 0: Base

    Used for flat surfaces that sit directly on the page or application background.

    <img
      alt="Shadow 0"
      title="Shadow 0"
      lightAlt="Shadow 0"
      darkAlt="Shadow 0"
      src="/images/Shadow-0-1.png"
      className="dark:hidden"
    />
    <img
      alt="Shadow 0"
      title="Shadow 0"
      lightAlt="Shadow 0"
      darkAlt="Shadow 0"
      src="/images/Shadow-0.png"
      className="hidden dark:block"
    />

    - Page background
    - Default content area
    - Flat card
    - Form section
    - Outlined component
    - Table surface

    ### 2. Shadow 1: Subtle

    Used for surfaces that require subtle separation from the background.

    ![Shadow 1 Subtle](/images/Shadow-1_-Subtle.png "Shadow 1 Subtle")

    - Elevated card
    - Search container
    - Sticky section
    - Clickable tile
    - Low-emphasis floating surface

    ### 3. **Shadow 2: Raised**

    Used for raised or persistent interface elements that sit above the main content.

    ![Shadow2](/images/Shadow2.png "Shadow2")

    - Sticky header setelah content di-scroll
    - Hovered card
    - Raised navigation
    - Floating action atau control
    - Draggable card dalam resting state

    ### 4. Shadow 3: Floating

    Used for temporary floating surfaces that appear above page content.

    ![Shadow3](/images/Shadow3.png "Shadow3")

    - Dropdown
    - Menu
    - Popover
    - Date or time picker
    - Floating panel
    - Rich tooltip

    ### 5. Shadow 4: Overlay

    Used for temporary surfaces that require stronger separation and visibility.

    ![Shadow4](/images/Shadow4.png "Shadow4")

    - Tooltip
    - Toast
    - Bottom sheet
    - Side panel
    - Floating notification
    - Command palette

    ### 6. Shadow 5: Modal

    Used for blocking surfaces that require immediate user attention.

    ![Shadow5](/images/Shadow5.png "Shadow5")

    - Modal
    - Dialog
    - Confirmation dialog
    - Critical decision surface
    - Blocking workflow

    ### 7. Shadow 6: Interaction

    Reserved for temporary interaction states that must appear above all standard surfaces.

    ![Shadow6](/images/Shadow6.png "Shadow6")

    - Dragged element
    - Drag preview
    - Reordering item
    - Temporary system overlay
    - Floating element selama direct manipulation

    <Info>
      **Note: **_Level 6 should not be used as a resting elevation. Apply it only while an interaction is in progress, then return the element to its previous elevation once the interaction ends._
    </Info>
