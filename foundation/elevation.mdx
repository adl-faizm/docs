The XLSMART elevation system communicates visual hierarchy and the spatial relationship between surfaces. Elevation helps users identify which elements are on the base surface, raised above content, or temporarily displayed as overlays.

## C. Usage

### 1. Shadow 0: Base

Used for flat surfaces that sit directly on the page or application background.

- Page background
- Default content area
- Flat card
- Form section
- Outlined component
- Table surface

### 2. Shadow 1: Subtle

Used for surfaces that require subtle separation from the background.

![Shadow 1 Subtle](/images/Shadow-1_-Subtle.png "Shadow 1 Subtle")

- Elevated card
- Search container
- Sticky section
- Clickable tile
- Low-emphasis floating surface

### 3. **Shadow 2: Raised**

Used for raised or persistent interface elements that sit above the main content.

## Shadow scale

| Token | Value | Usage |
| --- | --- | --- |
| `--shadow-none` | `none` | Flat surfaces, no depth |
| `--shadow-xs` | `0 1px 2px rgba(0,0,0,0.05)` | Subtle separation (table rows, avatars) |
| `--shadow-sm` | `0 1px 3px rgba(0,0,0,0.10), 0 1px 2px rgba(0,0,0,0.06)` | Cards, contained components |
| `--shadow-md` | `0 4px 6px rgba(0,0,0,0.07), 0 2px 4px rgba(0,0,0,0.06)` | Dropdowns, popovers |
| `--shadow-lg` | `0 10px 15px rgba(0,0,0,0.10), 0 4px 6px rgba(0,0,0,0.05)` | Floating panels, dialogs |
| `--shadow-xl` | `0 20px 25px rgba(0,0,0,0.10), 0 10px 10px rgba(0,0,0,0.04)` | Modals, overlays |
| `--shadow-2xl` | `0 25px 50px rgba(0,0,0,0.25)` | Full-screen drawers, sheets |

## Z-index scale

Elevation is also communicated through z-index. Use the provided z-index tokens to avoid stacking conflicts:

| Token | Value | Usage |
| --- | --- | --- |
| `--z-base` | 0 | Normal document flow |
| `--z-raised` | 10 | Sticky headers, inline overlays |
| `--z-dropdown` | 100 | Dropdowns, select menus |
| `--z-sticky` | 200 | Sticky navigation bars |
| `--z-modal-backdrop` | 300 | Modal backdrop overlay |
| `--z-modal` | 400 | Modal dialogs |
| `--z-toast` | 500 | Toast notifications |
| `--z-tooltip` | 600 | Tooltips (always on top) |

## Usage example

```css card.css
.card {
  box-shadow: var(--shadow-sm);
}

.dropdown-menu {
  box-shadow: var(--shadow-md);
  z-index: var(--z-dropdown);
}

.modal {
  box-shadow: var(--shadow-xl);
  z-index: var(--z-modal);
}
```

<Tip>
  Never use arbitrary z-index values like `z-index: 9999`. Always use a token from the z-index scale to avoid stacking conflicts across components.
</Tip>
