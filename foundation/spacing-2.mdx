    ## B. Border Width

    | Token | Value |
    | --- | --- |
    | `border.width.sm` | 1 px |
    | `border.width.md` | 2 px |

    ## C. Usage

    ### 1. Small Border

    Use the default border to define subtle component boundaries and separate related content without creating unnecessary visual noise.

    - Input boundary
    - Card outline, jika memang diperlukan
    - Divider
    - Table separator
    - Checkbox atau radio outline
    - Container boundary
    - Subtle structural separation

    ### 2. Medium Border

    Use strong borders only for states or elements that require additional emphasis. Do not use strong borders as the default outline for all components.

    - Selected state
    - Active navigation or tab
    - Focus indicator
    - Emphasized boundary
    - State yang memerlukan visibilitas lebih kuat

    ### 3. Pair width with semantic color

    Border width tidak boleh digunakan sendirian. Pair dengan semantic color sesuai konteks:

  <Tab title="Token">
    ## Token

    Border width sets the visual stroke thickness to define hierarchy, contrast, and boundaries between elements.

    | Token | Value | Usage |
    | --- | --- | --- |
    | `border.width.sm` | 1px | Default Border Width. Digunakan untuk 90% komponen UI (Card, Input Field, Table divider, Badge, Outlined Button). |
    | `border.width.md` | 2px | Active & Focus States. Digunakan untuk penanda visual yang lebih tegas (Selected Card, Active Tab indicator, Checkbox/Radio border, Focus Ring). |
  </Tab>
  <Tab title="Code">
    ## JSON

    ```json5
    {
      "border": {
        "width": {
          "sm":   { "$value": "1px", "$type": "borderWidth" },
          "md":   { "$value": "2px", "$type": "borderWidth" }
        }
      }
    }
    ```
