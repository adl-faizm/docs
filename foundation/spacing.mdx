XLSmart Design System uses a 4px base spacing scale. Every spacing value in the system is a multiple of 4, giving you predictable, harmonious layouts without guessing or approximating.

## Spacing scale

| Token | Value | Pixels | Usage |
|-------|-------|--------|-------|
| `--space-0` | 0 | 0px | No space |
| `--space-1` | 0.25rem | 4px | Micro gaps (icon-to-text) |
| `--space-2` | 0.5rem | 8px | Tight padding, compact elements |
| `--space-3` | 0.75rem | 12px | Small internal padding |
| `--space-4` | 1rem | 16px | Default padding, standard gap |
| `--space-5` | 1.25rem | 20px | Medium spacing |
| `--space-6` | 1.5rem | 24px | Card padding, section gaps |
| `--space-8` | 2rem | 32px | Large section spacing |
| `--space-10` | 2.5rem | 40px | Content section gaps |
| `--space-12` | 3rem | 48px | Layout section separation |
| `--space-16` | 4rem | 64px | Page-level vertical rhythm |
| `--space-20` | 5rem | 80px | Major section breaks |
| `--space-24` | 6rem | 96px | Hero/page header spacing |

## Usage guidelines

- **4–8px** — micro-spacing within dense UI elements (icon margins, tight list items)
- **12–16px** — default internal padding for components (buttons, inputs, cards)
- **24–32px** — gaps between components and content groups
- **48–64px** — vertical rhythm between page sections

## Applying spacing tokens

```css component.css
.card {
  padding: var(--space-6);         /* 24px all sides */
  margin-bottom: var(--space-4);   /* 16px below */
}

.button {
  padding: var(--space-2) var(--space-4);  /* 8px top/bottom, 16px left/right */
  gap: var(--space-2);                     /* 8px between icon and label */
}
```

```tsx stack-example.tsx
import { Stack } from '@xlsmart/design-system';

<Stack gap={4} padding={6}>
  <Component />
  <Component />
</Stack>
```

<Info>The `gap` and `padding` props on `Stack` and `Grid` accept spacing scale integers (1–24) that map directly to the spacing token scale.</Info>
