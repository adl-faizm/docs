    ## A. Overview & Principle

    <Frame>
      ![Spacing Thumbnail](/images/Spacing-Thumbnail.png "Spacing Thumbnail")
    </Frame>

    The XLSMART spacing system defines consistent distances within components and across layouts. It helps establish visual relationships, hierarchy, rhythm, and alignment across XLSMART digital experiences. Spacing must use approved tokens instead of arbitrary values.

    ## C. Usage

    ### 1. Use Spacing Based On Relationship

    Elements that are closely related should use smaller spacing. Separate groups or sections should use larger spacing.

    | **Unit (in px)** | **Suggested Usage** |
    | :-- | :-- |
    | 2-4 px | Optical adjustment and tightly related details |
    | 8 px | Gap between closely related elements |
    | 12-16 px | Internal component padding and content groups |
    | 20-24 px | Gap between related component groups |
    | 32-48 px | Gap between sections |
    | 64-96 px | Page-level or expressive layout spacing |

    ## A. Spacing Gap Token

    Used exclusively for spacing between two or more elements _(e.g., Icon to Text, Label to Field, Field to Field, Button Group)_.

    | Token Name | Token Alias | Value | Pixels | Usage |
    | --- | --- | --- | --- | --- |
    | `spacing.gap.0` | `space.0` | 0 | 0px | No space |
    | `spacing.gap.2xs` | `space.50` | 0.25rem | 4px | Icon-detail gap, compact UI, Micro gaps (icon-to-text) |
    | `spacing.gap.xs` | `space.100` | 0.5rem | 8px | Tight gap, compact/related elements |
    | `spacing.gap.sm` | `space.200` | 0.75rem | 12px | Small internal gap |
    | `spacing.gap.md` | `space.300` | 1rem | 16px | Default element gap |
    | `spacing.gap.lg` | `space.500` | 1.5rem | 24px | Group gap |
    | `spacing.gap.xl` | `space.600` | 2rem | 32px | Distinct element group |
    | `spacing.gap.2xl` | `space.700` | 2.5rem | 40px | Large component group |

    ## B. Spacing Padding Token

    Used exclusively for internal spacing within a container or component (e.g., Button Padding, Card Inner Padding, Modal Content Padding).

    | Token Name | Token Alias | Value | Pixels | Usage |
    | --- | --- | --- | --- | --- |
    | `spacing.padding.2xs` | `space.50` | 0.25rem | 4px | Compact badge/tag padding, button icon-only. |
    | `spacing.padding.xs` | `space.100` | 0.5rem | 8px | Vertical padding Small Button, Toast Notification inner space. |
    | `spacing.padding.sm` | `space.200` | 0.75rem | 12px | Vertical padding Medium/Large Button, Input Field inner padding. |
    | `spacing.padding.md` | `space.300` | 1rem | 16px | **Default Card/Container Padding** (Horizontal Button, Alert Box, Dropdown). |
    | `spacing.padding.lg` | `space.500` | 1.5rem | 24px | Medium Container Padding (Large Cards, Drawers, Table Containers). |
    | `spacing.padding.xl` | `space.600` | 2rem | 32px | Large Container Padding (Modal Dialogs, Large Popovers). |
    | `spacing.spacing.2xl` | `space.700` | 2.5rem | 40px | Hero Card / Banner Content Padding. |

    ## C. Spacing Layout Token

    Used exclusively for high-level page hierarchy boundaries (e.g., Section-to-Section spacing, Left-Right Page Margins, Hero Section Padding).

    | Token Name | Token Alias | Value | Pixels | Usage |
    | --- | --- | --- | --- | --- |
    | `spacing.layout.xs` | `space.600` | 2rem | 32px | Page Margin Kiri-Kanan (Desktop Small / Tablet Landscape). |
    | `spacing.layout.sm` | `space.800` | 3rem | 48px | **Section Gap Small** (Jarak antar Section Form ringan/Sub-section). |
    | `spacing.layout.md` | `space.900` | 4rem | 64px | **Default Section Gap** (Jarak antar Section utama, e.g., Profile ke Address). |
    | `spacing.layout.lg` | `space.1000` | 5rem | 80px | Outer Page Margin (Desktop Ultra-wide), Major Landing Page Section Gap. |
    | `spacing.layout.xl` | `space.1200` | 6rem | 96px | Hero Section Top/Bottom Space, Marketing Banner Clearance. |

    ## JSON

    ### 1. Primitive Token

    Ini adalah nilai piksel mentah (_hardcoded_) yang menjadi fondasi dasar seluruh _spacing_:

    ```json5
    {
      "spacing": {
        "0": { "value": "0px" },
        "50": { "value": "4px" },
        "100": { "value": "8px" },
        "200": { "value": "12px" },
        "300": { "value": "16px" },
        "400": { "value": "20px" },
        "500": { "value": "24px" },
        "60": { "value": "32px" },
        "700": { "value": "40px" },
        "800": { "value": "48px" },
        "900": { "value": "64px" },
        "1000": { "value": "80px" },
        "1200": { "value": "96px" }
      }
    }
    ```
