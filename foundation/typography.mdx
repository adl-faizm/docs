Typography tokens define the visual hierarchy of text in your UI. XLSmart Design System ships with a modular type scale, system font stacks, and weight utilities that keep text consistent and readable across all products.

## Font families

| Token | Value | Usage |
|-------|----------|-------|
| `--font-family-sans` | `'Inter', system-ui, sans-serif` | Body text, UI labels, everything by default |
| `--font-family-mono` | `'JetBrains Mono', 'Fira Code', monospace` | Code blocks, technical strings |

## Type scale

The type scale uses a modular ratio to ensure consistent visual hierarchy.

| Token | Size | Line Height | Usage |
|-------|------|-------------|-------|
| `--text-xs` | 12px / 0.75rem | 1.5 | Captions, helper text, labels |
| `--text-sm` | 14px / 0.875rem | 1.5 | Secondary body, form labels |
| `--text-base` | 16px / 1rem | 1.6 | Primary body text |
| `--text-lg` | 18px / 1.125rem | 1.5 | Large body, lead paragraphs |
| `--text-xl` | 20px / 1.25rem | 1.4 | Section headings (H4/H5) |
| `--text-2xl` | 24px / 1.5rem | 1.35 | Page sub-headings (H3) |
| `--text-3xl` | 30px / 1.875rem | 1.3 | Page headings (H2) |
| `--text-4xl` | 36px / 2.25rem | 1.25 | Hero headings (H1) |
| `--text-5xl` | 48px / 3rem | 1.1 | Display / hero text |

## Font weights

| Token | Value | Usage |
|-------|-------|-------|
| `--font-weight-regular` | 400 | Body text |
| `--font-weight-medium` | 500 | Labels, UI text |
| `--font-weight-semibold` | 600 | Subheadings, emphasis |
| `--font-weight-bold` | 700 | Headings, strong emphasis |

## Using typography tokens

```css component.css
.card-title {
  font-family: var(--font-family-sans);
  font-size: var(--text-xl);
  font-weight: var(--font-weight-semibold);
  line-height: 1.4;
  color: var(--color-neutral-900);
}

.card-body {
  font-size: var(--text-base);
  font-weight: var(--font-weight-regular);
  color: var(--color-neutral-800);
}
```

## Heading hierarchy

Use heading elements (`h1`–`h6`) semantically for document structure, then style them with typography tokens:

```tsx headings.tsx
import { Text, Heading } from '@xlsmart/design-system';

<Heading level={1} size="4xl">Page Title</Heading>
<Heading level={2} size="3xl">Section Title</Heading>
<Heading level={3} size="2xl">Subsection</Heading>
<Text size="base">Body paragraph text.</Text>
<Text size="sm" color="secondary">Caption or helper text.</Text>
```

<Tip>Always set heading levels based on document structure, not visual appearance. Use the `size` prop to control visual scale independently of semantic level.</Tip>
