       ## C. Typeface & Font Weight
       ### 1. Typeface & System Fallback
       XLSMART is the primary typeface used across XLSMART digital experiences. Approved fallback fonts must be used when the primary typeface is unavailable or does not support the required language or character set.
       <Check>
         Main Font: **XLSMART Sans**
       </Check>
       #### ⚠️ System Fallback
       Approved fallback fonts must be used when the primary typeface is unavailable or does not support the required language or character set.
       | Operating System | Font |
       | --- | --- |
       | Apple Ecosystem (iOS/macOS) | **SF Pro (-apple-system)** |
       | Windows Ecosystem | **Segoe UI** |
       | Android Ecosystem | **Roboto** |
       | Universal Fallback | **sans-serif** |
       ### 2. Font Weight
       Use only the approved font weights. Avoid using font weight as the only method of communicating meaning or hierarchy.
       | Weight | Usage |
       | --- | --- |
       | Regular, 400 | Body text, description, supporting text |
       | Semibold, 600 | Title, heading, button label |
       <Card title="Additional Rules:" type="info">
         - Use Regular weight for most content.
         - Use Semibold weight for emphasis.
       </Card>
       <Info>
         **_Note_**_: Using native system fonts as a fallback ensures that content remains instantly available (zero layout shift) without any "Flash of Unstyled Text" (FOUT) if the primary font encounters network-related issues._
       </Info>
       ## D. Type Scale
       Each typography style is a predefined combination of font family, font size, line height, font weight, and letter spacing. Do not modify individual properties or create custom text styles unless an approved style cannot support the intended use case.

    ## A. Applying Typography, Usage, and Hierarchy

    ### 1. Display

    Use for short, prominent messages, hero content, or significant data. Display styles should not be used for paragraphs or component content.

    | **Figma Text Style** | **Token** | **Size / Line height** | **Weight** | **Line Spacing** | Usage |
    | --- | --- | --- | --- | --- | --- |
    | Large | `font.display.large` | 64px / 88px | Semibold | -1% | <ul><li>Hero section sekunder</li><li>Product page headline</li><li>Major section opener</li><li>Marketing content yang masih perlu sangat menonjol</li></ul> |
    | Medium | `font.display.medium` | 48px / 64px | Semibold | -0.5% | <ul><li>Hero section sekunder</li><li>Product page headline</li><li>Major section opener</li><li>Marketing content yang masih perlu sangat menonjol</li></ul> |
    | Small | `font.display.small` | 40px/ 56px | Semibold | 0% | <ul><li>Section headline besar</li><li>Feature highlight title</li><li>Page header yang tidak membutuhkan hero treatment</li></ul> |
