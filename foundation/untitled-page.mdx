    ## Color Anatomy

    Colors represent XLSMART’s identity, from primary, secondary, and neutral colors, to semantic colors. To maintain visual consistency, accessibility (WCAG), and a clear interaction hierarchy across all XLSMART digital products, XLSMART Blue and XLSMART Magenta are assigned distinct systemic roles (Semantic Separation). This avoids color meaning conflicts and ensures an intuitive, consistent user experience.<br />Here’s why we separated the roles of primary blue and magenta:

    **1. Interaction Clarity (UX Safety & Clarity)**<br /> In UI/UX psychology, red/magenta tones naturally signal warnings or errors. Using XLSMART Blue as the Primary Interactive Color ensures users can easily spot main actions (buttons, links, controls) without worrying it's an error.

    **2. Accessibility Compliance (WCAG Compliance)**<br />XLSMART Blue (#1e22aa) offers a higher, more stable contrast ratio on light or white backgrounds, meeting [<u>WCAG 2.1</u>](https://www.w3.org/TR/WCAG21/) AA standards for text and interactive elements.

    **3. High-Impact Brand Moments**<br /> XLSMART Magenta (#e5005a) and the Future Gradient are super vibrant and high energy. Using them selectively as Brand Accents creates a much stronger visual impact for promo and marketing elements, rather than overusing them on every UI button.

    ## Color Scale Intent & Recommended Usage (Light Mode)

    | Shade Scale | Intent & Recommended Usage |
    | :-- | :-- |
    | **50** | Subtle Surface / Background Highlight (Latar belakang alert/toast/card) |
    | **100 – 200** | Disabled States, Subtle Borders, Divider (Disable Button, Disable Text, etc.) |
    | **300 – 400** | Component Borders, Focus Rings, Placeholder Icons (Card Border, focused state, etc.) |
    | **500 – 600** | Primary Brand & Main Interactive Elements (Tombol Utama) |
    | **700 – 800** | Hover / Pressed States & Sub-headers |
    | **900** | Primary Text (Light Mode) |
    | **950** | Dark Mode Surfaces / Deep Contrast Text |

    <Info>
      **_Note_**_: The shade mapping below is a base guide (recommended usage) to keep UI components consistent. Shade usage can be adjusted for special cases (like Dark Mode, high contrast, or complex components), as long as it still meets WCAG 2.1 AA contrast standards._
    </Info>
