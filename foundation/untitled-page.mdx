# Color Systems & Taxonomy

**Anatomy, Token Separation, Usage Rules, Do's & Don'ts**

---

## Color Anatomy

Colors represent XLSMART’s identity, from primary, secondary, and neutral colors, to semantic colors\[cite: 1\]. To maintain visual consistency, accessibility (WCAG), and a clear interaction hierarchy across all XLSMART digital products, **XLSMART Blue** and **XLSMART Magenta** are assigned distinct systemic roles (Semantic Separation)\[cite: 1\]. This avoids color meaning conflicts and ensures an intuitive, consistent user experience\[cite: 1\].

### Why We Separated Primary Blue and Magenta

1. **Interaction Clarity (UX Safety & Clarity)**<br />In UI/UX psychology, red/magenta tones naturally signal warnings or errors\[cite: 1\]. Using **XLSMART Blue** as the Primary Interactive Color ensures users can easily spot main actions (buttons, links, controls) without worrying it's an error\[cite: 1\].
2. **Accessibility Compliance (WCAG Compliance)**<br />**XLSMART Blue** (`#1E22AA`) offers a higher, more stable contrast ratio on light or white backgrounds, meeting WCAG 2.1 AA standards for text and interactive elements\[cite: 1\].
3. **High-Impact Brand Moments**<br />**XLSMART Magenta** (`#E5005A`) and the **Future Gradient** are super vibrant and high energy\[cite: 1\]. Using them selectively as Brand Accents creates a much stronger visual impact for promo and marketing elements, rather than overusing them on every UI button\[cite: 1\].

## Color Scale Intent & Recommended Usage (Light Mode)

| Shade Scale | Intent & Recommended Usage |
| :-- | :-- |
| **50** | Subtle Surface / Background Highlight (Latar belakang alert/toast/card)\[cite: 1\] |
| **100 – 200** | Disabled States, Subtle Borders, Divider (Disable Button, Disable Text, etc.)\[cite: 1\] |
| **300 – 400** | Component Borders, Focus Rings, Placeholder Icons (Card Border, focused state, etc.)\[cite: 1\] |
| **500 – 600** | Primary Brand & Main Interactive Elements (Tombol Utama)\[cite: 1\] |
| **700 – 800** | Hover / Pressed States & Sub-headers\[cite: 1\] |
| **900** | Primary Text (Light Mode)\[cite: 1\] |
| **950** | Dark Mode Surfaces / Deep Contrast Text\[cite: 1\] |

> **Note:** The shade mapping above is a base guide (recommended usage) to keep UI components consistent\[cite: 1\]. Shade usage can be adjusted for special cases (like Dark Mode, high contrast, or complex components), as long as it still meets WCAG 2.1 AA contrast standards\[cite: 1\].

## C. Semantic Colors

Semantic colors communicate system status, provide feedback, and give visual cues to users following universal UI/UX psychology standards\[cite: 1\].

### Info

Conveys neutral information, system hints, or non-critical updates (e.g., toast notifications, info banners, helper text)\[cite: 1\].

- **Shade Scale:** 50 (`#F0F9FF`) ⭐ – 950 (`#082F49`)\[cite: 1\]
- Key Shades: `100: #E0F2FE`, `500: #0EA5E9`, `700: #0369A1`\[cite: 1\]

### Success

Marks successfully completed actions, safe processes, or positive states (e.g., payment success badges, complete states, success toasts)\[cite: 1\].

- **Shade Scale:** 50 (`#F0FDF4`) ⭐ – 950 (`#052E16`)\[cite: 1\]
- Key Shades: `100: #DCFCE7`, `500: #22C55E`, `700: #15803D`\[cite: 1\]

### Warning

Gives early warnings or signals caution (e.g., system maintenance alerts, pending payments, storage limit warnings)\[cite: 1\].

- **Shade Scale:** 50 (`#FFFBEB`) ⭐ – 950 (`#451A03`)\[cite: 1\]
- Key Shades: `100: #FEF3C7`, `500: #F59E0B`, `700: #B45309`\[cite: 1\]

### Error

Indicates system failures, invalid inputs, or high-risk destructive actions (e.g., form validation errors, failed transaction alerts, delete confirmation)\[cite: 1\].

- **Shade Scale:** 50 (`#FEF2F2`) ⭐ – 950 (`#450A0A`)\[cite: 1\]
- Key Shades: `100: #FEE2E2`, `500: #EF4444`, `700: #B91C1C`\[cite: 1\]

## D. Future Gradient

Future Gradient is the main gradient color used for XLSMART branding\[cite: 1\]. It can be used as a background in two orientations\[cite: 1\]:

- **Vertical Layout:** XLSMART Magenta MUST be positioned on **top**\[cite: 1\].
- **Horizontal Layout:** XLSMART Magenta MUST be positioned on the **left side**\[cite: 1\].
