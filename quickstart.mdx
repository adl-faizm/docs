XLSmart Design System is distributed as an npm package. This guide walks you through installing the package, setting up styles, and rendering your first component in a React project.

## Prerequisites

Before you begin, make sure you have:

- Node.js 16 or higher
- A React project (Create React App, Vite, Next.js, or similar)
- npm, yarn, or pnpm

## Installation

<Steps>
  <Step title="Install the package">
    Add the XLSmart Design System package to your project:

    <CodeGroup>
    ```bash npm
    npm install @xlsmart/design-system
    ```
    ```bash yarn
    yarn add @xlsmart/design-system
    ```
    ```bash pnpm
    pnpm add @xlsmart/design-system
    ```
    </CodeGroup>
  </Step>

  <Step title="Import global styles">
    Import the base stylesheet at the root of your application. In a Next.js project, add it to `_app.tsx` or `layout.tsx`. In a Vite/CRA project, add it to `main.tsx` or `index.tsx`.

    ```tsx main.tsx
    import '@xlsmart/design-system/styles/base.css';
    import App from './App';
    ```

    <Tip>The base stylesheet loads all design tokens as CSS custom properties. Without it, components will not render correctly.</Tip>
  </Step>

  <Step title="Use your first component">
    Import a component and use it in your application:

    ```tsx App.tsx
    import { Button } from '@xlsmart/design-system';

    export default function App() {
      return (
        <Button variant="primary" onClick={() => alert('Hello!')}>
          Get Started
        </Button>
      );
    }
    ```
  </Step>

  <Step title="Explore components">
    Browse the [Components](/components/button) section to discover all available components, their props, and usage examples.
  </Step>
</Steps>
